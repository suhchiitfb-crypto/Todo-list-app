# To-Do List App

A simple command-line to-do list application built in Python as part of my journey learning software engineering.

## Features

- Add tasks
- View tasks (with done/not-done status)
- Mark tasks as done
- Remove tasks
- Clear all tasks
- Tasks are saved to a file, so your list persists between runs
